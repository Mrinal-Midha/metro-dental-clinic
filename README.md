# metro-dental-clinic

A responsive marketing website for Metro Dental Clinic — deployed live via GitHub Pages.

## What's here
- `index.html`, `style.css`, `script.js` — the main site (nav, service info, video sections).
- `mobile-test.html` — a mobile-layout test page.
- `assets/` — images and site assets; commercial video used on the site.

## Tech stack
Plain HTML, CSS, and JavaScript — no framework or build step.

## Running locally
Open `index.html` directly in a browser, or serve the folder with any static file server.
